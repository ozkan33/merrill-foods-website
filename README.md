# Merrill Foods LLC — Marketing Website

A fast, static marketing site for a specialty food distributor, built with
**Astro 5** + **Tailwind CSS v4**. Zero client-side framework JS, self-hosted
variable fonts, scroll-reveal animations that respect `prefers-reduced-motion`,
and a contact form that posts to a third-party endpoint (no backend).

- 🟢 **Home** — full-bleed autoplaying video hero, value props, supply categories, CTA band
- 🟢 **About** — editorial story, mission, values, credibility stats
- 🟢 **Contact** — form (Web3Forms), business details, hours, map placeholder

---

## Quick start

```bash
npm install
npm run dev      # http://localhost:4321
```

| Command           | Action                                   |
| ----------------- | ---------------------------------------- |
| `npm run dev`     | Start the dev server at `localhost:4321` |
| `npm run build`   | Build the production site to `./dist/`   |
| `npm run preview` | Preview the production build locally     |

Requires **Node 18.20+ / 20.3+ / 22+**.

## Where to swap in your video & poster

The hero video lives at **`src/assets/hero.mp4`** and the poster fallback at
**`src/assets/hero-poster.jpg`**. Replace either file in place — keep the same
filenames and the site picks them up automatically (Astro hashes & optimizes
them at build).

- **Video:** muted, looping, `playsinline`, no controls. It is deferred and
  only loads when the hero scrolls into view (and is skipped entirely under
  reduced-motion / Save-Data). Recommended: **H.264 MP4, ~1280×720, 5–10 MB,
  ≤ ~15 s loop.** (The included clip is 1280×720, 10 s, ~6 MB.)
  - _Optional WebM:_ add `src/assets/hero.webm`, then add a second `<source>`
    in [`src/components/Hero.astro`](src/components/Hero.astro).
- **Poster:** a JPG matching the video's aspect ratio (**1280×720**). It is the
  LCP image, so keep it well-compressed (~150–250 KB). It is `preload`ed with
  `fetchpriority="high"`.

> The included `hero-poster.jpg` is a generated brand-colored placeholder.
> Export a real frame from your video for production, e.g.:
> `ffmpeg -i src/assets/hero.mp4 -ss 00:00:01 -frames:v 1 -q:v 3 src/assets/hero-poster.jpg`

## Where to edit copy & contact info

**Everything lives in one file:** [`src/site.config.ts`](src/site.config.ts).

Company name, tagline, contact details (address, phone, email, hours), social
links, navigation, and all page copy (hero, features, supply categories, about
story, values, stats) are defined there. Edit once — it updates everywhere.

Search the file for **`TODO:`** to find the values you must supply before
launch (company name, real address/phone/email, map embed, form key).

### Brand theme tokens

Colors, fonts, and spacing are defined as Tailwind v4 theme tokens in
[`src/styles/global.css`](src/styles/global.css) under the `@theme { … }`
block (e.g. `--color-forest`, `--color-amber`, `--font-serif`). Change a value
there and it propagates through every `bg-forest` / `text-amber` / `font-serif`
utility across the site.

## Wiring up the contact form

The form uses **[Web3Forms](https://web3forms.com)** (free, no backend):

1. Go to [web3forms.com](https://web3forms.com) and enter your inbox email to
   get a free **Access Key**.
2. Open [`src/site.config.ts`](src/site.config.ts) and set:
   ```ts
   export const form = {
     accessKey: 'YOUR_WEB3FORMS_ACCESS_KEY', // ← paste it here
     // …
   };
   ```
3. Done. Submissions arrive in your inbox; visitors get inline success/error
   feedback without leaving the page. A honeypot field filters basic spam.

### Prefer Formspree?

1. Create a form at [formspree.io](https://formspree.io) and copy its endpoint
   (e.g. `https://formspree.io/f/abcdwxyz`).
2. In `src/site.config.ts` set `provider: 'formspree'` and
   `endpoint: 'https://formspree.io/f/abcdwxyz'`.
3. The hidden `access_key` field is harmless for Formspree, but you may remove
   it from [`src/components/ContactForm.astro`](src/components/ContactForm.astro).

## Map embed

The contact page shows a placeholder until you add a Google Maps embed URL.
In Google Maps: **Share → Embed a map → Copy the `src="…"` value**, then set
`contact.mapEmbedSrc` in `src/site.config.ts`.

## SEO checklist

- Per-page `<title>`, meta description, canonical URL, Open Graph + Twitter cards
  (see [`src/layouts/BaseLayout.astro`](src/layouts/BaseLayout.astro)).
- `sitemap-index.xml` auto-generated by `@astrojs/sitemap` on build.
- `public/robots.txt` references the sitemap.
- Favicon: `public/favicon.svg` (an `.ico` / `apple-touch-icon.png` / `og-image.jpg`
  are included as generated placeholders — replace with branded versions).

> **Before deploying:** set your real domain in
> [`astro.config.mjs`](astro.config.mjs) (`SITE_URL`) and in
> `public/robots.txt`. Canonical URLs, the sitemap, and OG image URLs all derive
> from it.

## Deploy

It's a fully static site (`npm run build` → `./dist/`). Any static host works.

**Netlify** — Build command `npm run build`, Publish directory `dist`.
(Or drag-and-drop the `dist/` folder.)

**Vercel** — Import the repo; the Astro preset sets build `npm run build` /
output `dist` automatically.

**Cloudflare Pages** — Framework preset **Astro**, build `npm run build`,
output directory `dist`.

No environment variables are required (the form key is a public client-side key).

## Accessibility & performance notes

- Semantic landmarks (`header`/`main`/`footer`/`nav`), skip-link, labeled form
  fields, keyboard-navigable, AA-contrast palette, visible focus rings.
- Reduced-motion: disables scroll-reveal, smooth scroll, and the hero video.
- Zero framework JS; tiny inline scripts for the navbar, reveal observer, video
  defer, and form. Fonts self-hosted (no render-blocking external request).
